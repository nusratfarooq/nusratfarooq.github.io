Topic 1

Simultaneous Linear Equations & Gaussian Elimination

Bewley begins with the most concrete possible question: how do you find x₁ and x₂ satisfying two equations at once?

📘 Bewley's Opening Example
x₁ + 7x₂ = −57 … (eq 1) 12x₁ + 3x₂ = 45 … (eq 2)

The idea: eliminate x₁ from equation 2 by computing 4×(eq1) − (1/3)×(eq2):

4x₁ + 28x₂ = −228 −(4x₁ + x₂ = 15) ───────────────────── 27x₂ = −243 → x₂ = −9 Then: x₁ = −7(−9) − 57 = 63 − 57 = 6
🧠 Visual Intuition
Each equation is a line in 2D space. Solving simultaneously = finding their intersection point. In higher dimensions (N unknowns), each equation is a hyperplane. The solution is where all hyperplanes meet.
The General Algorithm

Gaussian Elimination: The General Recipe

For M equations in N unknowns (equation 1.1 in the notes), the algorithm is:

1
Find the pivot column. Find the leftmost column with a non-zero entry (column n₁). Swap rows so the non-zero entry is on top.
2
Scale the pivot row. Divide by the leading entry so it becomes 1. This is the pivot.
3
Eliminate the column. For every other row m, subtract aₘₙ₁ × (pivot row) from row m, making all other entries in column n₁ equal to 0.
4
Recurse. Ignore the pivot row and repeat steps 1–3 on the remaining rows. Stop when no more non-zero rows exist.
5
Read off solutions. Free variables (non-pivot columns) can be set arbitrarily. Pivot variables are determined by formula (1.2) in the notes.
📌 Result: When does a solution exist?
After elimination, if any row has the form 0 = yₖ with yₖ ≠ 0, there is no solution. Otherwise, solutions exist and the free variables (N − K of them, where K = number of pivots) can be set freely.

Key Lemma
⭐ Lemma 1.1 (Critical for PhD Econ!)

If M < N and y = 0, then Ax = 0 has a non-zero solution.

Translation: Fewer equations than unknowns → you always have a non-trivial solution (the solution isn't just x = 0). In econ: if you have fewer constraints than free variables, the system is under-determined — many equilibria exist.

Topic 2

Matrix Representation of Linear Equations

Writing out equations one by one gets cumbersome fast. Matrices give us a clean notation. The M equations in N unknowns:

a₁₁x₁ + a₁₂x₂ + ⋯ + a₁ₙxₙ = y₁ a₂₁x₁ + a₂₂x₂ + ⋯ + a₂ₙxₙ = y₂ ⋮ aₘ₁x₁ + aₘ₂x₂ + ⋯ + aₘₙxₙ = yₙ

become the single compact equation:

Ax = y
Visual: How Matrix Multiplication Works
🧠 How to Think About It
The entry y₁ is the dot product of row 1 of A with x. Think of each row as a constraint — a hyperplane in N-dimensional space. The system Ax = y asks: where is the unique point (or set of points) satisfying ALL constraints simultaneously?
Row Reduced Echelon Form (RREF)

The Goal of Elimination: RREF

📌 Definition: Row Reduced Matrix
A matrix is row reduced if: (a) the first non-zero entry in any row is 1 (the leading entry), and (b) each column containing a leading entry has all other entries equal to 0.
📌 Definition: Row Reduced Echelon Matrix (RREF)
A row reduced matrix where: (a) all zero rows are at the bottom, and (b) the leading entries move strictly right as you go down (n₁ < n₂ < … < nₖ).

⭐ Lemma 1.3
Every matrix is row equivalent to a row reduced echelon matrix. (Proof: Gaussian elimination always terminates and produces RREF.)
Topic 3

Elementary Row Operations & Row Equivalence

Bewley formalizes the operations we used in Gaussian elimination. These are the "legal moves" that don't change the solution set.

📌 The Three Elementary Row Operations
a
Scale: Multiply any row by a non-zero number c.
Example: R₁ → 3R₁
b
Swap: Interchange two rows.
Example: R₁ ↔ R₂
c
Add: Replace a row by itself plus c times another row (c ≠ 0).
Example: R₂ → R₂ − 2R₁ (this is the key elimination step)
📌 Definition: Row Equivalence
Matrices A and B are row equivalent if B can be obtained from A by a finite sequence of elementary row operations.
⭐ Lemma 1.2 (Why This Is Safe)
If A and B are row equivalent, the equations Ax = 0 and Bx = 0 have the same solutions.

Why this matters: This guarantees that Gaussian elimination doesn't "lose" or "create" solutions. Every step is reversible — it's like doing legal algebraic manipulations on both sides of an equation.
🧠 The Augmented Matrix Trick
To solve Ax = y (not just Ax = 0), we form the augmented matrix (A : y) — append y as an extra column. Then apply row operations to (A : y). The same lemma guarantees we haven't changed the solution set. This is the standard algorithm taught in undergrad linear algebra.
Key Theorem from this Section
⭐ Theorem 1.4
If A is an M×N matrix with M < N (fewer rows than columns), then Ax = 0 has a non-zero solution.
⭐ Corollary 1.5
If A is an N×N (square) matrix and Ax = 0 has NO non-zero solution, then A is row equivalent to the N×N identity matrix I.
🧠 Economic Translation
Corollary 1.5 is the key to invertibility. If a square system of equations has a unique solution (only x = 0 solves the homogeneous system), then the matrix is invertible — meaning there's a unique solution for ANY right-hand side y. In econ: a square system of market-clearing conditions with a unique equilibrium corresponds to an invertible matrix.
Topic 4

Vector Spaces

Now Bewley steps back and abstracts. Instead of thinking only about ℝᴺ (N-tuples of real numbers), he defines the general concept of a vector space — any set with addition and scalar multiplication that obeys 10 rules.

📌 Definition: Vector Space
A vector space V is a non-empty set with operations addition (v + w) and scalar multiplication (cv) satisfying 10 axioms: closure under both operations, commutativity, associativity, zero vector, additive inverse, and distributive laws.
📌 Definition: Subspace
W is a subspace of V if W ⊆ V and W is itself a vector space under V's operations. Quick check: W is a subspace iff it's non-empty and closed under addition and scalar multiplication (i.e., v + w ∈ W and cv ∈ W for all v, w ∈ W and all scalars c).
⚠️ Common Mistake
A subspace must contain the zero vector. The set {(v₁, v₂) | v₁ + v₂ = 1} is NOT a subspace (it doesn't contain (0,0) and isn't closed under addition). Bewley's example {(v₁, v₂) | v₁ + v₂ = 0} IS a subspace because it passes through the origin.
Topic 5 — The Core of Lecture 1

Linear Independence, Spanning, and Bases

These concepts answer: what is the "minimal structure" needed to describe a vector space?

📌 Definitions

Linear Combination: v = c₁v₁ + c₂v₂ + ⋯ + cₙvₙ for some scalars cₙ.

Span: The set of ALL linear combinations of v₁, …, vₙ. (It's always a subspace.)

Spanning Set: v₁, …, vₙ span V if every vector in V is a linear combination of them.

Linearly Dependent: v₁, …, vₙ are dependent if ∃ scalars c₁, …, cₙ (not all 0) with c₁v₁ + ⋯ + cₙvₙ = 0.

Linearly Independent: Not dependent. The ONLY way c₁v₁ + ⋯ + cₙvₙ = 0 is cₖ = 0 for all k.

Basis: A set of independent vectors that span V.

Visual: Independence vs. Dependence
Key Theorems on Bases & Dimension
⭐ Theorem 1.6 — The Spanning Bound
If v₁,…,vₘ span V, then any independent set in V has at most M elements.
Proof idea: If you had N > M independent vectors w₁,…,wₙ, you could write each wₙ as a linear combination of the vₘ's. That gives an M × N coefficient matrix with M < N, so by Lemma 1.1, there's a non-trivial linear combination of the wₙ's equaling zero — contradicting independence.
⭐ Corollary 1.7 — Dimension is Well-Defined
Any two bases of a finite-dimensional vector space have the same number of elements. This number is the dimension of V, written dim V.
🧠 Why This Matters
Dimension is THE fundamental invariant of a vector space. ℝ³ has dimension 3 no matter which basis you use — whether you use {e₁,e₂,e₃} or three other independent vectors. In econ, the dimension of the solution set to Ax = 0 (called the null space) tells you exactly how many "degrees of freedom" you have — how many free parameters exist in the system.
⭐ Corollaries 1.8, 1.11 — The "Two out of Three" Rule
In a vector space of dimension N: any set of N vectors that (a) spans V is automatically independent (= a basis), or (b) is independent automatically spans V (= a basis).
You only need to check ONE of the two conditions when you already know you have exactly N vectors.
⭐ Theorem 1.15 — Unique Representation
If v₁,…,vₙ is a basis for V, every vector v ∈ V can be written uniquely as v = c₁v₁ + ⋯ + cₙvₙ. The numbers c₁,…,cₙ are the coordinates of v in this basis.
🧠 Why Theorem 1.15 is Powerful
This says every finite-dimensional vector space "looks just like ℝᴺ" once you fix a basis. The abstract space V is completely captured by N numbers. This is why economists can freely work in coordinate space without loss of generality.
Topic 6 — The Capstone of Lecture 1

Row Space, Column Space, and the Rank Theorem

📌 Definitions
For an M×N matrix A:
  • Row space: span of the rows of A (a subspace of ℝᴺ)
  • Column space: span of the columns of A (a subspace of ℝᴹ)
  • Row rank: dim(row space)
  • Column rank: dim(column space)
⭐ Theorem 1.18 — The Rank Theorem (Major Result!)
For any matrix A, row rank = column rank. We call this common number the rank of A.

Proof strategy: Reduce A to RREF (call it B). Lemmas 1.16 and 1.17 show row equivalence preserves both row rank and column rank. Then for RREF, directly verify both ranks equal K = number of non-zero rows (= number of pivot positions).
🧠 Why This is Surprising and Deep
The row space lives in ℝᴺ and the column space lives in ℝᴹ — they're in completely different spaces! Yet they always have the same dimension. This non-obvious fact is the heart of the rank-nullity theorem you'll use constantly in econometrics (for rank conditions in GMM/IV identification).
📘 Quick Example
A = | 1 2 3 | | 4 5 6 | | 7 8 9 |
Row 3 = 2×Row 2 − Row 1, so the rows are dependent. Row rank = 2. And sure enough, the column rank is also 2 (columns 1 and 2 are independent; column 3 = 2×col2 − col1). Rank(A) = 2.
⭐ Connection to Solvability
The equation Ax = y has a solution if and only if y lies in the column space of A. The rank tells you the dimension of that column space — i.e., how many "directions" in ℝᴹ the matrix A can "reach."
